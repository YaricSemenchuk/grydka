# Грядка — облік магазину насіння

Учёт прихода (выручки), себестоимости и чистой прибыли для небольшого магазина.
Интерфейс на украинском, суммы в гривнах.

- **Касса на Windows** — приложение `.msi` / `.exe`, работает и без интернета.
- **Mac владельца** — приложение `.dmg` или просто браузер.
- **Сервер** — хранит все операции, синхронизирует устройства, отдаёт веб-версию и каждый день делает резервную копию.

```
 Каса (Windows) ─┐                    ┌─ MacBook (застосунок)
                 ├──►  Сервер (HTTPS) ◄┤
 Телефон/браузер ┘   журнал операцій   └─ Веб-версія
```

## Как считается прибыль

```
Виторг − собівартість проданого − витрати − списання = чистий прибуток
```

- **Себестоимость** — по средневзвешенной закупочной цене. Партия пришла дороже — средняя пересчитывается сама.
- **Закупка не уменьшает прибыль сразу.** Товар идёт на склад, а в себестоимость попадает только при продаже.
- **Возврат** уменьшает выручку в день возврата, товар возвращается на склад по своей себестоимости.
- **Списание** (брак, порча, недостача по инвентаризации) — убыток по себестоимости.
- **Ошибочную операцию можно отменить.** Она остаётся в журнале зачёркнутой и не участвует в расчётах.
- **Деньги хранятся в копейках** (целые числа), количество — в тысячных долях, поэтому ошибок округления нет.

## Как устроена синхронизация

Каждое устройство пишет операции в свой локальный журнал (IndexedDB) и сразу показывает результат. Раз в 10 секунд, а также сразу после каждой операции, журнал отправляется на сервер, и с сервера приходят операции других устройств.

- Операции только добавляются и никогда не перезаписываются, поэтому конфликтов нет.
- Склад, себестоимость и отчёты каждое устройство пересчитывает из журнала одинаково.
- Нет интернета или света — касса продолжает работать, продажи уйдут на сервер позже.

## 1. Запуск сервера (VPS, например Hetzner / DigitalOcean, ~5 $/мес)

Нужен сервер с Docker и домен (A-запись на IP сервера).

```bash
git clone <репозиторий> gryadka && cd gryadka
cp .env.example .env
nano .env            # DOMAIN, SHOP_KEY (openssl rand -hex 16), SHOP_NAME
docker compose up -d
```

Через минуту веб-версия будет доступна по `https://ваш-домен`, HTTPS-сертификат Caddy получит автоматически.

- **Данные:** папка `./data` (`gryadka.db`).
- **Ежедневные копии:** `./data/backups`, хранятся 30 последних.
- **Обновление:** `git pull && docker compose up -d --build`.

**Без Docker.** Нужен Node.js 22.13 или новее:

```bash
cd app && npm ci && npm run build && cd ..
SHOP_KEY=ваш-ключ SHOP_NAME="Магазин насіння" node server/server.mjs
```

## 2. Сборка приложений для Windows и Mac

Собирает GitHub Actions, на своём компьютере ничего ставить не нужно:

1. Залить проект в репозиторий на GitHub.
2. Открыть **Actions → «Збірка застосунків» → Run workflow**.
3. Через ~15 минут скачать артефакты:
   - `gryadka-windows` — `.msi` и `.exe`;
   - `gryadka-macos` — `.dmg` (универсальный, для Intel и Apple Silicon).

Если запушить тег `v1.0.0`, файлы дополнительно попадут в черновик релиза.

**Важно:**
- **Windows** может показать «SmartScreen: неизвестный издатель», потому что приложение без платной подписи. Нажать «Подробнее → Выполнить в любом случае».
- **macOS** без подписи Apple: при первом запуске правый клик по приложению → «Открыть». Либо выполнить в терминале `xattr -cr /Applications/Gryadka.app`.
- Приложение для Mac подключается к серверу только по **HTTPS**.

## 3. Первый запуск

1. На кассе: «Підключити до сервера магазину» → адрес сервера, ключ магазина, имя устройства «Каса».
2. Добавить товары:
   - вручную;
   - или **Товари → Імпорт з Excel**: шаблон скачивается кнопкой «Шаблон для імпорту», колонки «Назва, Категорія, Од., Ціна продажу, Ціна закупівлі, Залишок, Мін. залишок, Штрихкод». Остатки из файла станут начальным приходом.
3. Владельцу: **Синхронізація → «Скопіювати посилання для власника»**. По ссылке веб-версия откроется сразу с ключом. Пересылать её только доверенным людям.

Горячие клавиши: **F2** — новая продажа, **F3** — новый расход, **Enter** — провести продажу. Сканер штрихкодов работает как клавиатура: сканируйте прямо в поле поиска.

## Демо-данные для показа заказчику

На **отдельном тестовом** сервере:

```bash
node server/demo-data.mjs https://test.ваш-домен КЛЮЧ
```

Скрипт добавит 18 товаров и около полутора месяцев продаж, закупок и расходов.

## Разработка

```bash
# терминал 1 — сервер
SHOP_KEY=dev-key-123 node server/server.mjs
# терминал 2 — фронтенд с горячей перезагрузкой (прокси /api → :8787)
cd app && npm i && npm run dev        # http://localhost:1420
# десктоп-оболочка (нужен Rust)
cd app && npm run tauri dev
# тесты расчёта прибыли
cd app && npm test
```

Структура:

| Путь | Что там |
|---|---|
| `app/src/core/ledger.ts` | расчёт склада, себестоимости, прибыли, отчётов (с тестами) |
| `app/src/core/store.ts` | локальное хранилище и синхронизация |
| `app/src/pages/*` | экраны |
| `app/src-tauri/` | оболочка Windows/macOS |
| `server/server.mjs` | сервер без внешних зависимостей (встроенный SQLite из Node.js) |

API сервера (заголовок `Authorization: Bearer <SHOP_KEY>`):

| Запрос | Что делает |
|---|---|
| `POST /api/sync` | `{cursor, events}` → `{events, cursor, more}` |
| `GET /api/export` | все операции в JSON |
| `GET /api/hello` | проверка ключа |
